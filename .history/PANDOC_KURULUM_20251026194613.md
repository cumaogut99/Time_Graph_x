# 📦 Pandoc Kurulum Rehberi

## Durum

Şu anda `pandoc-3.8.2.1/` klasöründe kaynak kodu var. Ancak bu çalıştırılabilir (executable) değil.

**İhtiyacınız olan:** Derlenmiş Windows executable (pandoc.exe)

---

## ✅ Önerilen Yöntem: Portable Versiyon (En Hızlı)

### Adım 1: İndirin

**Link:** https://github.com/jgm/pandoc/releases/download/3.8.2.1/pandoc-3.8.2.1-windows-x86_64.zip

**veya**

```cmd
setup_pandoc.bat
# Seçenek 2'yi seçin (Portable)
```

### Adım 2: ZIP'i Açın

- `pandoc-3.8.2.1-windows-x86_64.zip` dosyasını açın
- İçinde `pandoc.exe` dosyası bulunuyor

### Adım 3: Kopyalayın

**Seçenek A (Önerilen):**
```
C:\Users\MONSTER\Desktop\time_graph_x\tools\pandoc\pandoc.exe
```

**Seçenek B:**
```
C:\Users\MONSTER\Desktop\time_graph_x\pandoc.exe
(Ana klasöre direkt)
```

### Adım 4: Test Edin

```cmd
# Portable klasörden
tools\pandoc\pandoc.exe --version

# veya ana klasörden
pandoc.exe --version
```

**Beklenen Çıktı:**
```
pandoc 3.8.2.1
Features: +server +lua
Scripting engine: Lua 5.4
...
```

### Adım 5: HTML Oluşturun

```cmd
# Portable destekli script kullanın
build_html_portable.bat
```

## ❓ Sık Sorulan Sorular

### S: Kaynak kodu klasörü silebilir miyim?
**C:** Evet! `pandoc-3.8.2.1/` klasörünü silebilirsiniz. Sadece kaynak kod.

```cmd
rmdir /s /q pandoc-3.8.2.1
```

### S: Portable ile sistem kurulumu arasındaki fark?
**C:** 
- **Portable:** Sadece bu proje için, kurulum gerektirmez
- **Sistem:** Tüm bilgisayarda kullanılabilir, PATH'e eklenir

### S: Hangisi daha iyi?
**C:** Bu proje için **Portable** yeterli ve daha temiz.

### S: Script'ler otomatik buluyor mu?
**C:** Evet! `build_html_portable.bat` hem portable hem sistem kurulumunu otomatik bulur.

---

## 🔍 Sorun Giderme

### Hata: "pandoc: command not found"

**Sebep:** Pandoc henüz kurulmamış veya PATH'de değil.

**Çözüm:**
```cmd
# Portable varsa kullan
build_html_portable.bat

# Yoksa kur
setup_pandoc.bat
```

### Hata: "pandoc.exe bulunamadı"

**Kontrol edin:**
```cmd
# 1. tools\pandoc\ klasöründe var mı?
dir tools\pandoc\pandoc.exe

# 2. Ana klasörde var mı?
dir pandoc.exe

# 3. Sistem PATH'inde var mı?
where pandoc
```

**Çözüm:** Yukarıdaki adımları takip edin, pandoc.exe'yi kopyalayın.
