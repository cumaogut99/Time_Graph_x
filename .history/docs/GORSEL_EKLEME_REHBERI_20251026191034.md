## Görsel Düzenleme

### Gerekli Düzenlemeler

**1. İşaretleme:**
- Önemli butonları kırmızı dikdörtgenle çevir
- Oklar ile yönlendirme ekle
- Numaralama yap (1, 2, 3...)

**2. Boyutlandırma:**
- Genişlik: 1920px (Full HD)
- Yükseklik: Değişken (orantılı)
- Format: PNG (şeffaf arka plan için)

**3. Kalite:**
- DPI: 150 (print için)
- Compression: Lossless PNG

**Önerilen Araçlar:**
- **Paint.NET** (Ücretsiz, Windows)
- **GIMP** (Açık kaynak)
- **Photoshop** (Profesyonel)
- **Snagit** (Screenshot + Edit)

## Markdown'a Görsel Ekleme

### Görsel Ekleme Syntax'ı

**Şu anki placeholder'ı:**
```markdown
> 📸 **[Görsel 1: Uygulama Başlangıç Ekranı]**  
> _Splash screen ve ana pencere açılış görüntüsü_
```

**Gerçek görsel ile değiştir:**
```markdown
![Görsel 1: Uygulama Başlangıç Ekranı](screenshots/01_splash_screen.png)
_Splash screen ve ana pencere açılış görüntüsü_
```

### Toplu Değiştirme

**Find & Replace ile:**

Find:
```
> 📸 **\[Görsel (\d+): (.+?)\]**
```

Replace:
```
![Görsel $1: $2](screenshots/$1_*.png)
```

## PDF'e Dönüştürme

### Yöntem 1: Pandoc (Önerilen)

**Kurulum:**
```bash
# Pandoc indir: https://pandoc.org/installing.html
# MiKTeX indir: https://miktex.org/download (PDF için LaTeX gerekli)
```

**Dönüştürme:**
```bash
pandoc KULLANIM_KLAVUZU_TR.md -o KULLANIM_KLAVUZU_TR.pdf \
  --pdf-engine=xelatex \
  --toc \
  --toc-depth=2 \
  --number-sections \
  -V geometry:margin=2cm \
  -V fontsize=11pt \
  -V documentclass=report \
  -V lang=tr-TR
```

**Özellikler:**
- ✅ İçindekiler otomatik
- ✅ Sayfa numaraları
- ✅ Bölüm numaralandırma
- ✅ Türkçe karakter desteği
- ✅ Görseller dahil

### Yöntem 2: Typora (Kolay)

**Adımlar:**
1. Typora indir: https://typora.io/
2. KULLANIM_KLAVUZU_TR.md dosyasını aç
3. File → Export → PDF
4. Ayarları seç → Export

**Avantajlar:**
- ✅ Çok kolay
- ✅ WYSIWYG görünüm
- ✅ Güzel tema seçenekleri

### Yöntem 3: Markdown to PDF (VSCode)

**Adımlar:**
1. VSCode → Extensions
2. "Markdown PDF" uzantısını kur
3. Markdown dosyasını aç
4. Sağ tık → "Markdown PDF: Export (pdf)"

**Avantajlar:**
- ✅ VSCode'dan çıkmadan
- ✅ Otomatik
- ✅ Toplu dönüştürme

### Yöntem 4: Online (Hızlı Test)

**Web Siteleri:**
- https://www.markdowntopdf.com/
- https://md2pdf.netlify.app/
- https://dillinger.io/ (Export → PDF)

**Kullanım:**
1. Markdown içeriğini yapıştır
2. "Convert to PDF" tıkla
3. İndir

## PDF Özelleştirme

### Kapak Sayfası

**cover.md oluştur:**
```markdown
---
title: "Time Graph X"
subtitle: "Kullanım Kılavuzu"
author: "Time Graph X Development Team"
date: "Ekim 2025"
version: "v1.0.0"
---

\newpage
```

**Birleştir:**
```bash
pandoc cover.md KULLANIM_KLAVUZU_TR.md -o KULLANIM_KLAVUZU_TR.pdf
```

### Sayfa Ayarları

**custom-pandoc.yaml:**
```yaml
geometry:
  - margin=2.5cm
  - paper=a4paper
fontsize: 11pt
linestretch: 1.2
toc: true
toc-depth: 2
number-sections: true
lang: tr-TR
header-includes:
  - \usepackage{fancyhdr}
  - \pagestyle{fancy}
  - \fancyhead[L]{Time Graph X}
  - \fancyhead[R]{Kullanım Kılavuzu}
  - \fancyfoot[C]{\thepage}
```

**Kullanım:**
```bash
pandoc KULLANIM_KLAVUZU_TR.md -o output.pdf --defaults=custom-pandoc.yaml
```

## Otomasyonlu Workflow

### Tüm Adımları Otomatikleştir

**build_manual.bat (Windows):**
```batch
@echo off
echo Building Time Graph X User Manual...

REM 1. Görselleri kontrol et
echo Checking screenshots...
if not exist "screenshots\" (
    echo ERROR: screenshots folder not found!
    pause
    exit /b 1
)

REM 2. PDF oluştur
echo Converting Markdown to PDF...
pandoc KULLANIM_KLAVUZU_TR.md -o KULLANIM_KLAVUZU_TR.pdf ^
  --pdf-engine=xelatex ^
  --toc ^
  --toc-depth=2 ^
  --number-sections ^
  -V geometry:margin=2cm ^
  -V fontsize=11pt ^
  -V lang=tr-TR

if %errorlevel% neq 0 (
    echo ERROR: PDF conversion failed!
    pause
    exit /b 1
)

echo PDF created successfully!

REM 3. Dağıtım paketi oluştur
echo Creating distribution package...
mkdir dist 2>nul
xcopy /Y KULLANIM_KLAVUZU_TR.pdf dist\
xcopy /Y KULLANIM_KLAVUZU_TR.md dist\
xcopy /E /Y screenshots dist\screenshots\

echo Done! Check dist/ folder.
pause
```

**Kullanım:**
```cmd
build_manual.bat
```
