## 📋 Geliştirme Workflow

### Senaryo 1: Yeni Bug Tespit Edildi

1. **`ROADMAP.md`** → Bilinen Bug'lar bölümüne ekle
2. Detayları yaz (semptom, kök neden, süre)
3. `FEATURE_DEFINITIONS.md`'ye ekle (eğer büyükse)
4. Düzelt ve test et
5. `ROADMAP.md`'yi güncelle → Tamamlanmış bölümüne taşı

### Senaryo 2: Yeni Özellik Eklendi

1. **`ROADMAP.md`** → Öncelikli Geliştirmeler'e bak
2. Özelliği seç veya yeni ekle
3. **`FEATURE_DEFINITIONS.md`** → Detaylı tanım ekle
4. Kod yaz, test et
5. **`ROADMAP.md`** → Tamamlanmış'a taşı
6. **`KULLANIM_KLAVUZU.md`** → Kullanıcı dokümantasyonu güncelle

### Senaryo 3: Doküman Karışıklığı Var

1. İlgili bilgiyi bul
2. Hangisi güncel? (`Son Güncelleme` tarihine bak)
3. Güncel olmayanı arşivle veya sil
4. Tek kaynak ilkesi: Aynı bilgi iki yerde olmamalı
