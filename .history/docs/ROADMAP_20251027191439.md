## 🐛 Bilinen Bug'lar

### Kritik (P0)

#### 1. Filter Dialog State Kaybı
**Durum:** ❌ Açık  
**Öncelik:** Kritik  
**Etkilenen:** Tüm filtreleme işlemleri

**Semptom:**
- Range filter uygulanıyor, dialog kapatılıyor
- Dialog tekrar açıldığında filtre gösterilmiyor
- Filtre aktif görünüyor ama görselleştirme kaybolmuş

**Kök Neden:** Dialog state yönetimi eksik

**Çözüm:**
```python
# Dialog açılırken mevcut filtreyi yükle
dialog.load_current_filter_state(tab_index, graph_index)

# Dialog kapandığında state'i kaydet
dialog.save_filter_state()
```

**Dosyalar:**
- `src/ui/graph_advanced_settings_dialog.py`
- `time_graph_widget.py` → `_on_graph_settings_requested()`

**Tahmini Süre:** 4-6 saat

---

#### 2. Limit Lines Temizlenmiyor
**Durum:** ❌ Açık  
**Öncelik:** Kritik  
**Etkilenen:** Static Limits özelliği

**Semptom:**
- Static limit ekleme çalışıyor
- Limit kaldırma grafikten temizlemiyor
- Çift çizgi problemi (eski + yeni limit çizgileri)

**Kök Neden:** Limit line referansları kayboluyor

**Çözüm:**
```python
# limit_lines dict'inde referans sakla
self.limit_lines[graph_index] = []

# Temizleme metodunu çağır
_clear_limit_lines(plot_widget, graph_index)
```

**Dosyalar:**
- `time_graph_widget.py` → `_on_limits_applied_from_dialog()`
- `src/graphics/graph_renderer.py`

**Tahmini Süre:** 3-4 saat

## 📝 Notlar

### 🏗️ Kod Modülerlik Kuralı

> **KRİTİK:** Kod değişiklikleri yaparken MUTLAKA bu kurala uyulmalıdır

**KURAL:** Mevcut dosyaları büyütmek yerine, yeni özellikler için yeni modüller/dosyalar oluştur

#### Prensipler

1. **Single Responsibility Principle (SRP)**
   - Her dosya/modül tek bir sorumluluğa sahip olmalı
   - Dosya 500+ satırı geçiyorsa bölünmeyi düşün
   - `time_graph_widget.py` gibi monolitik dosyalar genişletilmemeli

2. **Yeni Özellik = Yeni Modül**
   ```
   Kötü Örnek ❌:
   - time_graph_widget.py'ye 200 satır yeni kod eklemek
   
   İyi Örnek ✅:
   - src/features/streaming_manager.py (yeni)
   - src/features/export_manager.py (yeni)
   - src/features/plugin_manager.py (yeni)
   ```

3. **Klasör Yapısı**
   ```
   src/
   ├── data/          # Veri işleme
   ├── graphics/      # Görselleştirme
   ├── managers/      # İş mantığı yöneticileri
   ├── ui/            # UI bileşenleri
   ├── utils/         # Yardımcı araçlar
   └── features/      # YENİ: Özellik modülleri
       ├── streaming/
       ├── export/
       └── plugins/
   ```

4. **Maksimum Dosya Boyutu**
   - **Widget/UI:** Max 300 satır
   - **Manager:** Max 500 satır
   - **Utility:** Max 200 satır
   - **Ana dosya (time_graph_widget.py):** Mevcut durum korunur, YENİ KOD EKLENMEMELİ

5. **Refactoring Stratejisi**
   - Büyük dosyalarda yeni özellik eklerken:
     1. Yeni modül oluştur
     2. İlgili fonksiyonları yeni modüle taşı
     3. Ana dosyada sadece import ve method call bırak

#### Örnek Uygulama

```python
# Kötü ❌: time_graph_widget.py'ye ekleme
def export_to_png(self, filepath, dpi=300):
    # 50+ satır kod
    pass

def export_to_pdf(self, filepath):
    # 80+ satır kod
    pass

# İyi ✅: Yeni modül oluştur
# src/features/export/export_manager.py
class ExportManager:
    def export_to_png(self, widget, filepath, dpi=300):
        # 50+ satır kod
        pass
    
    def export_to_pdf(self, widget, filepath):
        # 80+ satır kod
        pass

# time_graph_widget.py'de sadece:
from src.features.export.export_manager import ExportManager

def export_graph(self, format, filepath):
    self.export_manager.export(format, filepath)
```

- Modülerlik performansı etkilemez
- Lazy import kullanılabilir
- Gereksiz import'ları önle
