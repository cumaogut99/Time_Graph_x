#### 9.1. Multi-Tab Filter İzolasyonu ve Concatenated Mode Global Uygulama
**Durum:** ✅ Düzeltildi  
**Öncelik:** Kritik  
**Düzeltilme Tarihi:** 2025-10-27  
**Etkilenen:** Multi-tab filter yönetimi, Concatenated mode

**Semptom:**
- Tab 1, Graph 1'e segmented filter uygula
- Tab 2, Graph 1'e bak → ❌ **Filter orada da görünüyor!**
- Concatenated mode'da filter uygulandığında **sadece bir sekme** etkileniyor
- Beklenen: Segmented → İzole, Concatenated → Global

**Kök Neden Analizi:**

**1. Filter State'te tab_index Eksikliği:**
```python
# filter_manager.py - ÖNCEDEN

    self.active_filters[tab_index][graph_index] = filter_data.copy()

```

**Problem:** 
- Filter kaydedilirken `tab_index` sadece dict key olarak kullanılıyor
- Filter_data içine eklenmiyordu
- Reapplication sırasında hangi tab'a ait olduğu bilinmiyordu

**2. Filter Reapplication'da Yanlış Tab Kullanımı:**
```python
# time_graph_widget.py - ÖNCEDEN

    # ❌ YANLIŞ: Mevcut aktif tab'ı kullanıyor
```

**Problem:**
- `_reapply_active_filters()` tüm filtreleri döngüde çağırıyor
- Her filter için `_apply_range_filter()` çalışıyor
- Ama target tab bilgisi kaybolmuş
- Sonuç: Filter aktif tab'a uygulanıyor (YANLIŞ!)

**3. Concatenated Mode Sadece Tek Tab'a Uygulanıyordu:**

**Adım 1: Filter State'e tab_index Ekleme**
```python

# Temel pattern:
class ThrottledUpdater:
    def __init__(self, interval_ms=50):
        self.interval = interval_ms
        self.last_update_time = 0
        self.timer = QTimer()
        self.timer.setSingleShot(True)
        
    def on_event(self, data):
        current_time = time.time() * 1000
        elapsed = current_time - self.last_update_time
        
        if elapsed >= self.interval:
            # Hemen güncelle
            self.update(data)
            self.last_update_time = current_time
            self.timer.stop()
        else:
            # Timer ile planla
            if not self.timer.isActive():
                remaining = self.interval - elapsed
                self.timer.setInterval(int(remaining))
                self.timer.start()
```

```python
def _use_existing_time_column(self, df, settings):
    original_series = df.get_column(time_column_name)
    
    # ✅ FIX: Önce dtype kontrol et
    if original_series.dtype == pl.Datetime:
        logger.info("Already Datetime (parsed by Polars)")
        converted_series = original_series
    else:
        # String ise birden fazla format dene
        datetime_formats = [
            None,  # Polars auto-detect
            "%d/%m/%Y %H:%M:%S%.f",  # 01/01/2024 10:00:00.000
            "%d/%m/%Y %H:%M:%S",     # 01/01/2024 10:00:00
            "%Y-%m-%d %H:%M:%S%.f",  # 2024-01-01 10:00:00.000
            "%Y-%m-%d %H:%M:%S",     # 2024-01-01 10:00:00
            "%Y-%m-%d",              # 2024-01-01
            "%d/%m/%Y",              # 01/01/2024
        ]
        
        for fmt in datetime_formats:
            try:
                if fmt is None:
                    converted_series = original_series.str.to_datetime(strict=False)
                else:
                    converted_series = original_series.str.strptime(
                        pl.Datetime, format=fmt, strict=False
                    )
                
                # Başarılı mı kontrol et
                if converted_series.null_count() < len(converted_series):
                    logger.info(f"Datetime parsing: {fmt or 'auto'}")
                    break
```

```python
def parse_time_column(self, data, time_col):
    """Zaman kolonunu akıllıca parse et (DEPRECATED - Yukarıdaki çözüm kullanılıyor)"""
    
    # Format algılama
    sample = str(data[time_col].iloc[0])
    
    # HH:MM:SS formatı (sadece saat)
    if re.match(r'^\d{2}:\d{2}:\d{2}$', sample):
        # Saati saniyeye çevirme, datetime olarak tut
        data[time_col] = pd.to_datetime(data[time_col], format='%H:%M:%S')
    
    # YYYY-MM-DD HH:MM:SS (tam datetime)
    elif 'T' in sample or ' ' in sample:
        data[time_col] = pd.to_datetime(data[time_col])
    
    # Unix timestamp
    else:
        data[time_col] = pd.to_numeric(data[time_col])
    
    return data
```

## 📝 Notlar

### 🏗️ Kod Modülerlik Kuralı

> **KRİTİK:** Kod değişiklikleri yaparken MUTLAKA bu kurala uyulmalıdır

**KURAL:** Mevcut dosyaları büyütmek yerine, yeni özellikler için yeni modüller/dosyalar oluştur

#### Prensipler

1. **Single Responsibility Principle (SRP)**
   - Her dosya/modül tek bir sorumluluğa sahip olmalı
   - Dosya 500+ satırı geçiyorsa bölünmeyi düşün
   - `time_graph_widget.py` gibi monolitik dosyalar genişletilmemeli

2. **Yeni Özellik = Yeni Modül**
   ```
   Kötü Örnek ❌:
   - time_graph_widget.py'ye 200 satır yeni kod eklemek
   
   İyi Örnek ✅:
   - src/features/streaming_manager.py (yeni)
   - src/features/export_manager.py (yeni)
   - src/features/plugin_manager.py (yeni)
   ```

3. **Klasör Yapısı**
   ```
   src/
   ├── data/          # Veri işleme
   ├── graphics/      # Görselleştirme
   ├── managers/      # İş mantığı yöneticileri
   ├── ui/            # UI bileşenleri
   ├── utils/         # Yardımcı araçlar
   └── features/      # YENİ: Özellik modülleri
       ├── streaming/
       ├── export/
       └── plugins/
   ```

4. **Maksimum Dosya Boyutu**
   - **Widget/UI:** Max 300 satır
   - **Manager:** Max 500 satır
   - **Utility:** Max 200 satır
   - **Ana dosya (time_graph_widget.py):** Mevcut durum korunur, YENİ KOD EKLENMEMELİ

5. **Refactoring Stratejisi**
   - Büyük dosyalarda yeni özellik eklerken:
     1. Yeni modül oluştur
     2. İlgili fonksiyonları yeni modüle taşı
     3. Ana dosyada sadece import ve method call bırak

#### Örnek Uygulama

```python
# Kötü ❌: time_graph_widget.py'ye ekleme
def export_to_png(self, filepath, dpi=300):
    # 50+ satır kod
    pass

def export_to_pdf(self, filepath):
    # 80+ satır kod
    pass

# İyi ✅: Yeni modül oluştur
# src/features/export/export_manager.py
class ExportManager:
    def export_to_png(self, widget, filepath, dpi=300):
        # 50+ satır kod
        pass
    
    def export_to_pdf(self, widget, filepath):
        # 80+ satır kod
        pass

# time_graph_widget.py'de sadece:
from src.features.export.export_manager import ExportManager

def export_graph(self, format, filepath):
    self.export_manager.export(format, filepath)
```

- Modülerlik performansı etkilemez
- Lazy import kullanılabilir
- Gereksiz import'ları önle
